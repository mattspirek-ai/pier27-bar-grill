# Pier 27 Bar & Grill

Public goodwill one-pager for **Pier 27 Bar & Grill** (Kerrville, TX).

**Live:** https://mattspirek-ai.github.io/pier27-bar-grill/

## Files

| Path | Purpose |
|------|---------|
| `index.html` | Single-page site (hero, about, hours, map, contact) |
| `styles.css` | Dark rustic riverside styling |
| `assets/` | Official logos (circular + wordmark), favicon |

## Local preview

From this folder:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Notes

- Hours are soft (~11 AM – midnight); exact hours/specials → Facebook.
- No fake reviews, menu items, or day-by-day hours.
- Customer-facing page has no agency branding.
