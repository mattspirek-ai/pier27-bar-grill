# Pier 27 Bar & Grill

Public goodwill one-pager for **Pier 27 Bar & Grill** (Kerrville, TX).

**Live:** https://mattspirek-ai.github.io/pier27-bar-grill/

## Files

| Path | Purpose |
|------|---------|
| `index.html` | Single-page site (hero, about, menu, hours, gallery, map, contact) |
| `styles.css` | Dark rustic riverside styling |
| `assets/` | Official logos (circular + wordmark), favicon |
| `assets/photos/` | Six venue photos used by the hero, mosaic and gallery |

## Local preview

From this folder:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Notes

- Hours are 11 AM – 12 AM daily (per the Facebook profile); specials → Facebook.
- No fake reviews. Menu items and prices come from the current menu flier;
  the flier lists entrées not yet on the page.
- Customer-facing page has no agency branding.
